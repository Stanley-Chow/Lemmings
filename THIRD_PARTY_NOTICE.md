# Third-party material and authorship

This project was built on a provided application framework.

My gameplay implementation is contained in:

- `Actor.h`
- `Actor.cpp`
- `StudentWorld.h`
- `StudentWorld.cpp`

The remaining engine/framework source files and the files under `Assets/` were
provided as project support material. They are retained so the gameplay
implementation can be built and evaluated as a complete working program; they
are not represented as original work.

SFML is an external dependency and is not vendored in this repository. It is
available under the zlib/png license from <https://www.sfml-dev.org/>.
