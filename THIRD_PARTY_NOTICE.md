# Third-party material and authorship

This project began from the framework supplied for UCLA CS 32 Project 3.

The portfolio author's implementation is contained in:

- `Actor.h`
- `Actor.cpp`
- `StudentWorld.h`
- `StudentWorld.cpp`

The remaining engine/framework source files and the files under `Assets/` were
provided with the assignment. They are included in this local release candidate
only so the implementation can be built and evaluated as a working program.
